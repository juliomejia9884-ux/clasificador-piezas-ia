## Descripción

Sistema que lee senales de sensores mientras una pieza pasa frente a ellos,
clasifica de que tipo es con un modelo de aprendizaje de maquina y acciona
un actuador para enrutarla. Crece semana a semana con los temas del curso:
adquisicion, caracteristicas, clasificacion, anomalias y despliegue en PLC.
